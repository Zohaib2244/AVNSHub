Design Notes
Project List — orange dot + pulsing stage label = AI currently active on that project. Cyan dot = widget exists in the codebase (Created).
Pipeline bar — orange highlight = stage you're viewing, cyan dot = stage has data, hollow dot = untouched. Every stage is always clickable.
Project name is editable inline in the workspace top bar. New projects default to "Untitled" until a brief title is generated or the user types one.
Deletion — only In Progress projects can be deleted from the creator (× button appears on hover). Created projects cannot be deleted here; deleting a widget from Hub Core Widget Manager automatically removes its project entry.
Back navigation (← Projects) is blocked while AI is generating — the button is greyed out/inert until the run completes or is stopped.
Pre-existing widgets (built before this system) appear in Created with empty Plan/Ideate stages — they can be opened and worked on like any other project.
