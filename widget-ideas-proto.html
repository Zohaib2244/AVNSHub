Clock & Date — redesign fully buildable

The current widget (ClockWidget.tsx) already works, but it doesn't branch on size at all — same time/date/tint-bar/lofi/theme/calendar stack regardless of S or M, and it only registers S/M (no L) in the manifest. This redesign: (1) actually differentiates each size, matching how the rest of the framework's widgets behave, (2) turns the plain day-progress bar into a segmented "glyph strip" — lit/dim ticks with a pulsing current-position glow — which is the "Glyph-style status pulse" idea already sitting in CLAUDE.md's backlog, applied here instead of left unbuilt, and (3) adds a new L size with a real navigable month calendar (today's date is live; the prev/next arrows below actually work). Time/date tick live, same as the current widget.

S — 1×2v (glance only — time, date, mini strip)
M — 2×2v (+ glyph strip, lofi, theme — current content)
L — 2×3v (+ navigable calendar — new tier)

Advanced Quick Links fully buildable

Same idea as Game Links, flattened — no game grouping, just tagged shortcuts, search/filter, drag-reorder (not shown in this static demo). Favicons here are placeholder initials; the real widget could fetch them via each site's /favicon.ico or a favicon-proxy API route. Worth knowing: there's already a widget registered under the id "quicklinks" (config/widgets.tsx, component QuickLinks.tsx) — but it's a static row of hardcoded links read from config/links.ts, with no in-UI add/edit/delete at all. This widget is meaningfully more capable (real CRUD), so it's worth building, just under a different slug (e.g. shortcuts or site-links) to avoid colliding.

Glyph Visualizer fully buildable

Scoped down per your note: no system-wide media detection, no track text, no header — just the glyph light bars, driven entirely by your existing real Spotify "now playing" poll (/api/now-playing, already working). Playing → bars pulse; paused or nothing playing → bars settle low and dim. Not literally frequency-reactive (Spotify's API gives play/pause + track state, not a raw waveform) — it's a stylized pulse tied to real playback state, the same honest tradeoff Ambient Sound's own visualizer doesn't have to make (that one analyzes audio it generates itself).
